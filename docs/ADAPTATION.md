# Адаптація під іншу майстерню

## Без програміста (кабінет `/admin`)

| Розділ | Що змінюється |
|---|---|
| Прайс | тариф за м² фасаду для 4 типів корпусних меблів; кухня (низ, верх, стільниця за пог. м, кутовий модуль, острів); % за 4 матеріали фасадів і 2 матеріали корпусу; % преміум-фурнітури; % складної форми; 9 опцій за одиницю; мінімум; % монтажу; демонтаж; ціна заміру (0 — безкоштовно); доставка; доплата за місто; підйом за поверх; крок заокруглення |
| Майстерня | назва, опис, юр. назва, телефон, Telegram, Viber, email, години роботи, місто, зона виїзду, акцент (4 готові), строки виготовлення для кожного типу, **палітра матеріалів** (до 12 кольорів, назва, текстура дерева в 3D), строк зберігання даних |
| Гра | вимкнено / без знижки / бонус; сума, строк, мінімум наступного замовлення; список кодів і ручне погашення |
| Персонажі | характер (привітний / спокійний / грайливий), обличчя й репліки увімк./вимк. |
| Сповіщення | Telegram-чат для нових заявок (пошук чату кнопкою, тестове повідомлення), телефон і адреса в повідомленні увімк./вимк. Токен бота — змінна `NUXT_TELEGRAM_BOT_TOKEN` на сервері |
| Доступ | зміна пароля (закриває інші сеанси), вихід |

## Потребує правки коду (оцінюється окремо)

| Що | Де | Орієнтовно |
|---|---|---|
| Логотип і знак | `app/components/layout/LogoMark.vue`, `public/icons/icon.svg`, потім `pnpm icons` | 1–2 год |
| Повна палітра, шрифти | `app/assets/styles/_themes.scss`, `_tokens.scss`, шрифти в `nuxt.config.ts` | 2–4 год |
| Тексти сторінок, FAQ, кроки | `app/pages/index.vue`, `shared/content/services.ts` | 1–3 год |
| Що входить / не входить, які опції доступні для типу | `shared/content/services.ts` (`SERVICES`, `TYPE_OPTIONS`) | 0,5–1 год |
| Межі розмірів і стартові конфігурації | `shared/limits.ts` (`SIZE_LIMITS`, `defaultConfig`) | 0,5–1 год |
| Імена й репліки персонажів | `shared/content/characters.ts` | 1 год |
| Форма чи кольори персонажів | `app/three/characters.ts`, `app/three/parts.ts`; GLB для Blender — `pnpm export:models` | від 4 год на героя |
| Вигляд меблів у 3D (профілі, ручки, цоколь, пропорції кухні) | `app/three/furniture.ts` | від 4 год |
| Новий тип меблів (наприклад, ліжко чи стіл) | тип у `shared/types.ts`, ціна в `shared/pricing.ts`, схема, прайс, 3D-будівник, тести | 1–3 дні |
| PWA-назва й кольори | `public/manifest.webmanifest`, `nuxt.config.ts` (theme-color) | 0,5 год |
| Мова, валюта, формат телефону | тексти в шаблонах, `formatUah`, `PHONE_RE` у `shared/limits.ts` | 4–8 год |

## Не входить у шаблон (окремий проєкт)

- Робочі креслення, експорт деталювання й розкрою, інтеграція з програмами розкрою (Базис, PRO100, Viyar).
- Облік матеріалів і складу, розрахунок собівартості.
- Онлайн-оплата й передоплата.
- Розклад замірників і монтажників, календар зайнятості, кілька ролей і менеджерів.
- CRM-інтеграції, SMS, email-сповіщення; Telegram-бот для клієнтів (статус заявки в боті), сповіщення про зміну статусу.
- Автоматичне погашення бонус-кодів і захист гри від накруток.
- AR-перегляд меблів у кімнаті.
- Кілька майстерень в одному екземплярі.

## Регулярні витрати покупця

| Стаття | Орієнтовно |
|---|---|
| Хостинг Node (VPS або PaaS) | 5–20 $/міс |
| PostgreSQL (керований), якщо не вбудована база | 0–25 $/міс; для старту часто вистачає безкоштовного тарифу Neon або Supabase |
| Домен | 10–20 $/рік |
| Бекапи бази | зазвичай входять у тариф PostgreSQL або VPS |

Платних API, LLM і підписок застосунок не потребує: репліки персонажів написані заздалегідь, меблі й персонажі будуються в браузері з коду.
